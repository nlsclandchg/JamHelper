# 果醬解謎助手（JamHelper）

《無盡冬日》繽紛刨冰舖小遊戲的自動解謎 APK：自動數瓶子、記住每一格放錯過的顏色，每輪挑「最可能對」的放法，盡量少用果醬。

## 建置 APK（GitHub Actions）
1. 在 GitHub 建一個新儲存庫，把這個資料夾的所有檔案（含 `.github` 資料夾與 `app/jamhelper.keystore`）上傳。
2. 上傳後會自動建置；到 **Actions** → 最新一次執行 → 下方 **Artifacts** 下載 `JamHelper-apk`，解壓縮得到 APK。
3. 簽章固定，之後更新版本可直接覆蓋安裝。

## 手機設定（需 Android 11 以上）
1. 安裝 APK，打開「果醬解謎助手」→ 開啟無障礙設定 → 開啟本服務。
2. 若顯示「受限制的設定」：設定 → 應用程式 → 果醬解謎助手 → 右上角 ⋮ → 允許受限制的設定。
3. 進入遊戲訂單畫面，按浮動視窗「▶ 開始」。浮動視窗請放在畫面上半部。

## 運作方式
- 每 0.4 秒截圖一次，辨識下方托盤的瓶子、平台格數、哪些格子變綠。
- 連續兩張畫面相同才動作，避開動畫。
- 記錄每格「已確定」與「已知錯誤」的顏色，在所有仍可能的排列中選預期命中最多的放法。
- 點擊後畫面沒變化或跳出其他畫面（例如果醬用完）會立刻自動停止。

## 檔案
- `Detector.java`：畫面辨識（托盤瓶子、平台格子、綠格、上一排碎果醬）
- `Solver.java`：選擇最省果醬的放法
- `Brain.java`：每輪流程與記憶
- `JamService.java`：無障礙服務（截圖、點擊、浮動視窗）
